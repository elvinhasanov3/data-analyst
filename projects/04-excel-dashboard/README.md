# 📊 Excel Sales Dashboard

**Goal:** Build a fully interactive sales dashboard in Excel using Power Query, Pivot Tables, and dynamic charts.

**Stack:** Microsoft Excel · Power Query · Pivot Tables · Charts · Slicers

---

## 📌 Features

- Automated data cleaning with Power Query
- Dynamic Pivot Tables for Sales, Profit, Quantity
- Interactive slicers (Region, Category, Year)
- KPI summary cards
- Trend charts and top products ranking

## 🛠️ How it was built

1. **Power Query**: cleaned dates, removed blanks, standardized categories
2. **Data Model**: created relationships between tables
3. **Pivot Tables**: multiple views (by region, by product, by month)
4. **Charts**: line chart for trends, bar chart for top products
5. **Slicers & Timeline**: for easy filtering
